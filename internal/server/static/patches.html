Patch lists and block lists

A patch list says what may be applied; a block list says what may not. Both are rules — severity, operating system, name patterns, minimum age — over whatever is pending. An endpoint no patch list covers may receive everything; block lists always subtract. Every deployment, bulk, scheduled or single-device, is narrowed this way before it is sent. Agents older than 0.44.0 cannot apply a narrowed set and are refused with the reason.

Repository lists

A repository list scopes a Linux host's scan/apply to a specific set of repos instead of whatever's natively configured on it. A host with no list assigned keeps using its official distro repos, unchanged. Which patches may then be applied is decided by Patch Lists, not here.

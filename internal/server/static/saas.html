Fewer than 5 page loads is no score, not a good one. Pick an app for its trend and its endpoints.

App library

The extension measures only these apps, matched by domain: a domain covers its subdomains, so slack.com includes app.slack.com. Every other site, and every incognito window, is ignored. Only an app's ID and the library domain that matched leave the browser — never a page's path, query, title or content. A domain can belong to one app.

Monitoring

Off by default. While on, every agent registers the extension's native messaging host for Chrome, Edge and Chromium and hands the extension the app library; the extension still has to be installed in the browser (below). Turning it off removes the host registration and discards what was waiting to be sent. Endpoints need an agent with SaaS monitoring and the Self Service listener enabled.

Extension package

Pack the extension with a key you keep (the key decides the extension ID; never upload it), then upload the .crx here. mustra checks its signatures and serves it, with an update manifest, to browsers that force-install it. Upload each new version packed with the same key.
